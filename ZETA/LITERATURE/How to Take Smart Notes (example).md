# How to Take Smart Notes (example)

> Example literature note (`type: literature_note`). A literature note captures *your distillation* of a source in your own words — not a copy of it. Put the source link in `reference`.

Key ideas (paraphrased):

- Separate **fleeting**, **literature**, and **permanent** notes; only the last are kept long-term.
- Write while you read — turn passive reading into notes you can reuse.
- A writing workflow is a chain: source → literature note → permanent note → draft.
