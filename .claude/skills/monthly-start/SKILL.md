# Monthly Start

1. Open this month's monthly note (`DAILY/MONTHLY`); if missing, create it from the monthly template.
2. Read **last month's** monthly note `## 🗺️ Next Month` (Theme / OKR draft / milestones).
3. Propose this month's `# 🧭 Monthly Plan & Goals` — Monthly Theme, Monthly OKR (O + KRs), key events/deadlines; confirm with the user and write them in.

Keep it short. Only fill the planning sections; leave the review sections for the monthly review.
