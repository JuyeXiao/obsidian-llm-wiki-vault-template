# Exploratory Data Analysis

> Example note inside an Area (`type: area_note`). It shows up in the parent Area's "Notes" tab automatically.

Exploratory Data Analysis (EDA) is the first pass over a new dataset: understand its shape before modeling anything.

- **Look at the shape** — rows, columns, types, missing values.
- **Univariate** — distributions of each variable; spot skew and outliers.
- **Bivariate** — relationships and correlations between variables.
- **Question the data** — how was it collected? what could bias it?
